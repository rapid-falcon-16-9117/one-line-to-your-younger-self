A single line to send back to a younger self: "Call your brother back the night you turn twenty-one — it's the last time he picks up, and you'll keep dialling his number for nine years." (138 characters.) A bittersweet micro-story with one named person, one exact age and one final image that stays — chosen by a pairwise judge-simulator tournament over 16 candidates against the brief's criteria in order (told to a younger self; only this older self could say it; lands in one breath; carries a turn; honest and specific enough to sting).

## Run it

```sh
python3 main.py
```
